C. MainComponent.cpp — getNextAudioBlock() modification
════════════════════════════════════════════════════════════════════════

At the top of getNextAudioBlock(), BEFORE the noise gate is applied and
AFTER the InputRouter fills the buffer, insert:

    // --- Input Trim ---
    // Convert the slider's dB value to a linear gain and scale the buffer.
    {
        const float trimGain =
            juce::Decibels::decibelsToGain (
                static_cast<float> (inputTrimSlider.getValue()));
        bufferToFill.buffer->applyGain (bufferToFill.startSample,
                                        bufferToFill.numSamples,
                                        trimGain);
    }
    // ------------------

The exact insertion point should be immediately after:
    inputRouter.fillBuffer (*bufferToFill.buffer, ...);
and BEFORE:
    noiseGate.process (...);

If there is a muted-output early-return path (tuner / outputMuted flag),
make sure the trim is applied BEFORE that path exits, or apply it to the
dry signal only — depending on whether trim should affect the tuner feed
(recommended: apply trim BEFORE tuner so the tuner sees the trimmed signal).
